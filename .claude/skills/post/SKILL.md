# /post — content in Shawn's actual voice

## Before writing anything

1. **Which project?** If it isn't obvious from context, ask — one question, not a form. Voice differs per project and getting it wrong wastes the whole draft.
2. **Read the voice sources, in this order:**
   - `context/how-i-talk.md` — always. This is the baseline.
   - `projects/<name>/CLAUDE.md` — project-specific rules.
   - For Underdog City: `brand-identity.md` (which voice — the man or the King), `content-engine.md` (pillar, platform format, CTA, hashtags), `project-reference.md` (lore and song facts, so nothing gets invented).
3. **Which platform?** Format follows platform. For UC during launch week the formats are already specified in `content-engine.md` — use them, don't improvise.

## Voice rules — non-negotiable

Casual, conversational, warm. Like talking to a friend, not addressing an audience.

**Never write anything that reads as AI-generated.** Specifically banned:

- "It's not just X, it's Y" and every variant of that construction
- Over-explaining — saying the thing, then saying it again in different words
- Hollow filler: "in today's world", "let's dive in", "here's the thing"
- Rule-of-three lists that exist for rhythm rather than meaning
- Corporate jargon of any kind
- Walls of text

For Underdog City, keep the two voices separate and never blend them in one piece:

- **The man (Kazo / Shawn)** — fan-facing captions, replies, emails. Real, direct, warm.
- **The Crowned King** — in-world copy, lyric-adjacent lines, hype. Dark, mythic, defiant. _"We all rule down here… turn that shit up loud."_

## Output

Give **3 options, not 1** — Shawn wants choices. Distinct angles, not three rewrites of the same sentence. Label what makes each different in about four words.

Then say which one you'd pick and why, in one line.

Include the CTA the project's docs specify. For UC launch week that's exactly one: **"Claim your key. theunderdogcity.com"** — presave is secondary, and never both in the same post.

Add hashtags only if the project doc defines sets. Use the set that matches the angle.

## Hard stop

**Never post, publish, schedule, or send anything.** Draft only, in chat or in a file. Publishing is Shawn's call every single time, no exceptions, no "I'll just queue it up."
